## Shared ASO checklist (all locales)

Do once per release, then apply per language above.

### Priority
1. Ship localized What's New (not “Bug fixes…”).
2. Update promotional text (no new binary / no review).
3. Refresh keywords — no overlap with title or subtitle.
4. Put book → pantry/cook-from-stock → barcode in screenshot slots 1–3.
5. Localize screenshot captions (IT first, then EN, then the rest).

### Description tip
Only the first ~3 lines show before “more”. Lead with:
1. Book-style recipes  
2. Pantry that knows what you can cook  
3. Shopping list that refills stock  

Mention barcode, widget, Live Activity timers, and iCloud near the top. Keep Pro / pricing below the fold.

### Ratings & growth
- Ask for a review after a successful cook or pantry refill — not on launch.
- Reply to reviews in IT + EN; mention 1.1.4 features in replies.
- Optional: Custom Product Pages for “food waste / pantry” vs “recipe book”; Search Ads on those exact terms + brand `Foo`.

### Before submit
- [ ] Release notes set for every locale
- [ ] Promo text updated
- [ ] Keywords checked vs title/subtitle
- [ ] First 3 screenshots match What's New
- [ ] Privacy labels still accurate (camera for barcode)
